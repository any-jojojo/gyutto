# アカウント削除の実行検証

対象：`demo-gyutto-deletion` のAuth・Firestoreエミュレーターと架空データ。実際にAdmin SDKで削除を実行した。本番アカウント・メールボックス・バックアップを削除した検証ではない。

結果：削除検証と既存ルール・Functionsの回帰スイートが成功（子プロセス終了コード0）。一時記録の早期消去拒否と待機後の消去も成功。`app/build/deletion-suite.log` に実行ログを保存。Functionsテスト44件（承認10、安全管理17、通報17）、既存招待・権限テスト、安全管理Rules40項目、通報Rules27項目を含む。ポリシーリンクと既存画面のFlutterテスト24件、静的解析も成功。

## 再実行

`app` で `npm run test:deletion`。Node、Java、appとfunctionsの依存関係が必要。`scripts/account-deletion.cjs` はlocalhostの両エミュレーターとdemoプロジェクト以外の実行を拒否する。本番実行用CLIではない。

## 対象と確認事項

- dry runで本人データ・子コレクション・以前の家族・親文書のないサブコレクションも列挙。dry runは変更しない。
- 家族管理者の単独削除は引継ぎ前に拒否し、Authの無効化も行わない。引継ぎ後は削除可能。
- Authを無効化・refresh token失効・削除。本人のprofile、members、投稿、他者投稿の本人既読、chatAccess、chatSafetyEvents、再設定申請、招待と両索引、過去の参加申請を削除。
- 他者の所属・承認・利用許可記録からcreatedBy、reviewedBy、permissionUpdatedBy等の本人参照を除去。他者の本文・既読・成人確認・Authは保持。
- 将来機能の通報データが検証環境に存在した場合も、本人に関連する通報・連投制御記録を除去。今回の本番で通報を有効化するものではない。
- 削除後のメール・パスワードによる再ログインをAuthエミュレーターにリクエストし、失敗することを確認。
- 削除前UIDを持つ認証コンテキストで、家族チャット読取、本人profile再作成、新規家族作成、削除制御記録の削除を試し、Rulesが拒否することを確認。実機のキャッシュ表示が即座に消えることを保証する試験ではない。
- 削除を再実行しても完了し、参加前／拒否済みアカウントも削除できる。対象外の親はチャットを閲覧可能。
- 一時記録を除いたデータを再走査し、対象UIDの参照がないことを確認。自由文に他者が書いた個人情報はUID参照の自動検出だけでは除去できないため、申請内容に応じ別途調査する。

## 削除中のアクセス阻止

Authの削除・refresh token失効だけでは発行済みIDトークンの有効期間を即座に消せない。[Firebaseのセッション管理](https://firebase.google.com/docs/auth/admin/manage-sessions)に合わせ、サーバー専用 `accountDeletions/{uid}` を作成してから所属を削除する。今回追加したRulesはこの記録があるUIDの直接アクセスを拒否する。参加承認Functionsも、承認者または子どもに削除記録がある場合は拒否し、削除中の所属再作成を防ぐ。

一時記録に保存するのはUID（文書ID）、開始日時、Auth削除完了日時のみ。`finishDeletion` はAuth削除後2時間以上の経過、Authユーザー不存在、関連データ不存在を確認して一時記録も消去する。テストでは待機前の拒否と、時刻を過去に設定した待機後の消去を確認する。2時間の実時間待機をしたテストではない。自動TTLや定期実行は追加していないため、担当者が翌日の完了確認で消去する。失敗した場合は記録を残したまま再調査し、完了と報告しない。

## 本番運用への適用条件・限界

- 今回のRulesと承認Functionsは未デプロイ。削除中アクセス阻止を本番で利用するには、保留中の投稿規約・通報を除いたリリース構成へ必要な変更のみ取り込む。
- 本番実行では本人確認・依頼範囲・引継ぎ・担当者確認が必要。検証モジュールの接続制限を外して本番に転用しない。本番規模に適したページング、再開記録、同時更新制御を別途整備する。全件走査の今回モジュールは検証用。
- この検証は個人の削除。家族全体の一括削除、実際の本人確認メール、端末キャッシュ消去、クラウドのログ・バックアップ・SDK識別子の消去、保存期間の運用は検証していない。
- Firebase側の処理期間と運営のliveデータ削除を分けて説明する。全コピーの即時消去や「実運用まで検証完了」とは申告しない。
