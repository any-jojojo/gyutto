# Screen List

このドキュメントは、ぎゅっとアプリで必要になる画面を整理するための設計書です。

初回リリースは Android を対象にし、Android リリース後に iOS 対応へ進みます。

## MVP Screens

| ID | Screen | Purpose | Main Users | Priority |
| --- | --- | --- | --- | --- |
| SC-001 | Splash / Loading | Firebase 初期化とログイン状態確認を行う | 全員 | Must |
| SC-002 | Welcome | 家族アカウント作成または招待コード参加を選ぶ | 未ログインユーザー | Must |
| SC-003 | Login | Firebase Authentication でログインする | 全員 | Must |
| SC-004 | Create Family | 家族管理者が家族アカウントを作成する | 家族管理者 | Must |
| SC-005 | Join Family | 招待コードで既存家族アカウントへ参加する | 親 | Must |
| SC-006 | Set Parent Password | 親が初回ログイン時に本人のパスワードを設定する | 親 | Must |
| SC-007 | Home | 家族情報、チャット入口、家族管理入口を表示する | 全員 | Must |
| SC-008 | Family Members | 家族メンバー一覧と役割を表示する | 全員 | Must |
| SC-009 | Add Parent | 家族管理者が親アカウントを追加し、招待コードを発行する | 家族管理者 | Must |
| SC-010 | Add Child | 家族管理者または親がこどもアカウントを追加し、初期パスワードを設定する | 家族管理者, 親 | Must |
| SC-011 | Child Invite Confirm | こどもが家族参加を確認する | こども | Must |
| SC-012 | Edit Child Profile | こどもが表示名を確認・変更する | こども | Must |
| SC-013 | Family Chat | 家族全員が同じ共有チャットを利用する | 全員 | Must |
| SC-014 | Account Settings | 自分の表示名やログアウトを扱う | 全員 | Should |

## Screen Details

### SC-001: Splash / Loading

Firebase 初期化、ログイン状態、所属家族の有無を確認します。

遷移先:

- 未ログインなら `Welcome`
- ログイン済みで家族所属ありなら `Home`
- ログイン済みで初回設定が必要なら該当設定画面

### SC-002: Welcome

未ログインユーザー向けの入口画面です。

主要アクション:

- 家族アカウントを作成する
- 招待コードで参加する
- ログインする

### SC-003: Login

Firebase Authentication を使ってログインします。

こどもアカウントはメールアドレス必須にしないため、ログイン方法の詳細は `docs/auth_and_roles.md` で定義します。

### SC-004: Create Family

家族管理者が最初に家族アカウントを作成する画面です。

入力項目:

- 管理者の表示名
- 家族名
- ログイン情報

作成後:

- 作成者を家族管理者として登録する
- 家族用共有チャットを利用可能にする
- `Home` へ遷移する

### SC-005: Join Family

招待コードで既存家族アカウントへ参加する画面です。

入力項目:

- 招待コード

参加後:

- 親アカウントの場合は `Set Parent Password` へ遷移する
- 既に初期設定済みなら `Home` へ遷移する

### SC-006: Set Parent Password

親アカウントが初回ログイン時に本人のパスワードを設定する画面です。

入力項目:

- 新しいパスワード
- パスワード確認

### SC-007: Home

ログイン後の基本画面です。

表示内容:

- 家族名
- 自分の役割
- 共有チャットへの入口
- 家族メンバー一覧への入口
- 権限がある場合のメンバー追加入口

### SC-008: Family Members

家族メンバーと役割を一覧表示します。

表示内容:

- 家族管理者
- 親
- こども

権限別アクション:

- 家族管理者は親追加とこども追加ができる
- 親はこども追加ができる
- こどもは追加ボタンを表示しない

### SC-009: Add Parent

家族管理者だけが利用できる親アカウント追加画面です。

入力項目:

- 親の表示名

作成後:

- 招待コードを発行する
- 親に招待コードを共有できる状態にする

招待コードの有効期限は、この画面の発行結果エリアで表示します。表示例は `Invite Code Expiration Display` にまとめます。

### SC-010: Add Child

家族管理者または親が利用できるこどもアカウント追加画面です。

入力項目:

- こどもの表示名
- 初期パスワード

ルール:

- こどもアカウントにメールアドレスは必須にしない
- こどもは家族メンバーを追加できない
- 初期パスワードは家族管理者または親が設定する

作成後:

- こども用の招待リンクを発行する
- 親または家族管理者の画面に招待用 QR コードを表示する
- こどもは自分のスマホで QR コードを読み取る
- QR コードから招待リンクを開くと `Child Invite Confirm` へ遷移する

QR コード表示:

- 招待リンクを QR コード化して表示する
- QR コードの下に有効期限を表示する
- 有効期限表示は親招待コードと同じ形式にする
- 有効期限は1時間とする
- 必要に応じて招待リンクの再発行ボタンを表示する
- メール送信は主導線にしない

### SC-011: Child Invite Confirm

こどもが QR コードから招待リンクを開いた後、家族への参加を確認する画面です。

表示内容:

- `{家族名} 家族に参加しますか？`
- `はい` ボタン
- `いいえ` ボタン

遷移:

- `はい` を選択したら `Edit Child Profile` へ遷移する
- `いいえ` を選択したら参加せずに終了する

### SC-012: Edit Child Profile

こどもが家族参加時に自分の表示名を確認・変更する画面です。

入力項目:

- 表示名

主要アクション:

- 登録

登録後:

- こどもアカウントを家族に参加済みとして更新する
- `Home` へ戻る

### SC-013: Family Chat

家族全員が同じ共有チャットを利用する画面です。

表示内容:

- メッセージ一覧
- メッセージ入力欄
- 送信ボタン
- メッセージごとの既読者

ルール:

- 画像送信は行わない
- メッセージ編集は許可しない
- メッセージ削除は許可しない
- 既読者は常時表示する
- 個別チャットや複数グループチャットは作らない

### SC-014: Account Settings

自分のアカウントに関する最小限の設定画面です。

MVP で扱う内容:

- 表示名の確認
- 自分の役割の確認
- ログアウト

## Role-Based Access

| Screen | 家族管理者 | 親 | こども |
| --- | --- | --- | --- |
| Home | Yes | Yes | Yes |
| Family Members | Yes | Yes | Yes |
| Add Parent | Yes | No | No |
| Add Child | Yes | Yes | No |
| Child Invite Confirm | No | No | Yes |
| Edit Child Profile | No | No | Yes |
| Family Chat | Yes | Yes | Yes |
| Account Settings | Yes | Yes | Yes |

## Invite Expiration Display

親アカウントの招待コード有効期限は、`Add Parent` の招待コード発行結果エリアに表示します。

こども用 QR コードの有効期限は、`Add Child` の QR コード表示エリアに同じ形式で表示します。

表示ルール:

- 有効期限内は「残り時間 + 日時」で表示する
- 有効期限切れの場合は期限切れメッセージを表示する

表示例:

| State | Text |
| --- | --- |
| 有効期限内 | `あと1時間有効  2026/07/29 18:00まで` |
| 有効期限切れ | `有効期限が切れました。再発行してください。` |

期限切れ時は、同じ画面で招待コードを再発行できる導線を表示します。

## Out of Scope Screens

初回リリースでは、次の画面は作りません。

- LINE 連携画面
- 複数グループチャット作成画面
- 個別チャット画面
- 画像送信画面
- こども招待メール送信画面
- メッセージ編集画面
- メッセージ削除確認画面
- 管理者向けダッシュボード
- 課金画面
- Web 専用画面
- iOS 専用画面

## Password Reset Screens

こどもアカウントのパスワード再設定は、親の許可を必要とします。

MVP では、既存画面の中に次の導線を置きます。

| Action | Screen |
| --- | --- |
| こどもが再設定リクエストを送る | Account Settings |
| 親が再設定リクエストを確認・許可する | Family Members |
| こどもが新しいパスワードを設定する | Login または Account Settings |

親が許可した場合のみ、こどもは新しいパスワードを設定できます。
