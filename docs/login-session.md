# 同じ端末でログイン状態を維持する

Android・iOSのFirebase Authenticationは認証セッションを端末に保存する。
従来は起動時に必ず未ログイン用ホームを表示しており、保存済みセッションを起動画面の選択に使っていなかった。

起動ルートに`SessionGate`を追加し、`authStateChanges()`の最初の通知を待つ。
復元中は「ログイン状態を確認しています…」を表示し、ログイン済みなら既存の`LoggedInHomeScreen`へ進む。
家族・役割・参加承認状況は従来どおりFirestoreから取得し、子供アカウントは既存の安全確認・保護者許可ゲートを経てチャットへ進む。
未ログインの場合は従来のホームを表示する。認証状態の取得エラーでは再試行を案内し、自動的なログアウトやアカウントの作り直しは行わない。

パスワードをアプリ独自のファイルへ保存しない。Firebase SDKのセッション管理を使用する。
明示的なログアウト、アプリデータの削除、認証セッションの無効化などでは再ログインが必要になる。
安全確認・子どもの利用許可の判定は省略しない。

検証対象：復元待ち、ログイン済みでの再起動相当の再マウント、未ログイン、認証消失・別ユーザーへの切り替え、取得エラーからの再試行。
実機ではアプリを終了・再起動し、家族管理者・親・子供それぞれの画面へ再ログインなしで進むことを確認する。
