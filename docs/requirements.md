# Requirements

このドキュメントは、ぎゅっとアプリの要件を整理するための設計書です。

## Purpose

ぎゅっとは、Flutter と Firebase を土台に開発する、独立した家族専用アプリです。

家族アカウントに参加しているメンバーだけが、家族内のシンプルなチャットを利用できます。LINE 連携は行いません。

## Current Assumptions

- Flutter アプリは `app/` に配置する
- Firebase プロジェクトは `gyutto-cb454` を使用する
- Android package name は `com.example.gyutto` とする
- iOS bundle ID は `com.example.gyutto` とする
- 初回リリース対象は Android とする
- Android リリース後に iOS 対応へ進む
- GitHub リポジトリは `any-jojojo/gyutto` とする
- LINE 連携は行わない
- 家族管理者、親、こどもの3種類の役割を扱う
- 家族ごとに1つの共有チャットを持つ
- Firebase Authentication を使う
- 既存家族アカウントへの参加は招待コードを使う
- 親アカウントは初回ログイン時に本人がパスワードを設定する
- こどもアカウントは家族管理者または親が初期パスワードを設定する
- こどもアカウントにメールアドレスは必須にしない
- 家族管理者は親アカウントを追加できる
- 家族管理者と親はこどもアカウントを追加できる
- 親招待コードとこども用 QR コードの有効期限は1時間とする
- こどもアカウントのパスワード再設定は、親へのリクエストと親の許可を必要とする
- 既読者表示は常時表示する
- メッセージの編集と削除は許可しない
- チャットで画像送信は行わない

## MVP Scope

初回リリースに向けた最小構成は、次の範囲から決めます。

- アプリの初期画面
- 家族管理者による家族アカウント作成
- 家族管理者による親アカウント追加
- 家族管理者または親によるこどもアカウント追加
- 家族メンバー全員が見られる共有チャット
- メッセージごとの既読者表示
- 役割に応じたアカウント追加制御
- 招待コードによる家族アカウント参加
- 親とこどもで異なる初期パスワード設定フロー
- Firebase Authentication によるログイン

## Out of Scope for MVP

初回リリースでは、次の内容は必要性を確認してから扱います。

- 複雑な管理画面
- 多言語対応
- 有料課金
- 高度な分析機能
- 管理者向けダッシュボード
- LINE 連携
- 複数グループチャット
- 家族外ユーザーとのチャット
- こどもアカウントによる家族メンバー追加
- こどもアカウントへのメールアドレス必須化
- メッセージ編集
- メッセージ削除
- チャットでの画像送信
- 初回リリースでの iOS 対応
- 初回リリースでの Web 対応
