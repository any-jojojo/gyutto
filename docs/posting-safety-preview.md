# 投稿規約・通報のプレビュー

2026-10-02 の決定：この機能は今回の本番リリースに含めず、実装とプレビューを将来検討用に保持する。詳細は `moderation-operations.md` の「今回のリリース判断」を参照。

```powershell
cd app
flutter run --no-pub -d web-server --target lib/preview/posting_safety_preview.dart --web-hostname 127.0.0.1 --web-port 8757
```

http://127.0.0.1:8757 を開く。「投稿する」で製品と同じ規約ダイアログを表示し、同意・拒否を試せる。同意した場合は第1版・仮の確認日時と投稿を表示する。

「投稿を通報」「ユーザーを通報」は製品と同じダイアログを使い、理由・補足をプレビュー内の受付記録に追加する。送信失敗を試すスイッチ、記録のリセットも用意。

Firebase は初期化せず、同意・投稿・通報はメモリ内だけに保存。表示日時は端末時刻であり、本番のサーバー記録ではない。再読み込みで消える。サーバーへの保存・制限の検証用ではない。

検証: `flutter test --no-pub test/posting_safety_preview_test.dart` 成功（同意拒否→同意→投稿→投稿通報→ユーザー通報→リセット）。静的解析も成功。ブラウザー接続が利用できず、ブラウザーの自動操作は未実施。
