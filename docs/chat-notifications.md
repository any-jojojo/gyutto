# 家族チャットの通知（Android）

## 動作

- 新規メッセージ作成時に、送信者以外の未読の家族メンバーへFCMで通知する。
- アプリを閉じている間はAndroidが通知を表示する。前面で別画面を見ている間はネイティブ通知を表示する。
- 通知音・振動・通知欄表示は「家族チャット」チャンネルで管理する。実際の音と表示は端末の通知許可、マナーモード、おやすみモードに従う。
- 通知をタップすると家族チャットを開く。現在のログインユーザーと家族を照合し、既存の安全確認・保護者許可ゲートを通す。
- チャット閲覧中は前面通知を抑制する。既読処理はチャットが前面かつアプリがアクティブな場合だけ行う。
- 設定画面の「メッセージ通知」からAndroidの通知設定を開ける。
- 未承認・利用停止・削除処理中のユーザー、および同意情報のないユーザーには送らない。
- iOSとWebのプッシュ通知は今回の対象外。

## 登録と管理

`registerChatPushDevice` / `unregisterChatPushDevice` の認証済みCallable経由で
`chatPushDevices/{SHA256(token)}` にトークンと所有者を保存する。
このコレクションはクライアントから読み書きできない（既存ルールのデフォルト拒否）。
同じトークンを複数アカウントに紐付けない。ログアウト前に登録を削除し、FCMトークンを破棄する。
無効トークンは送信エラー時に削除し、30日以上更新のない端末へは送らない。
生のトークンやメッセージ本文をアプリログに出力しない。

送信時に最新の既読状態を確認する。送信後に別端末で既読になった場合、すでに配送中の通知を取り消すことはできない。
送信履歴と1分間の送信リースで再試行・並行実行の重複を抑制し、同じメッセージのAndroid通知は同じタグで置き換える。
FCM送信直後に関数が停止した場合、完全な一度だけの配信は保証できない。

## 再デプロイ・配布手順

1. `app/` で通知用の3関数のみをデプロイする。

   ```powershell
   npx firebase deploy --project gyutto-cb454 --only functions:registerChatPushDevice,functions:unregisterChatPushDevice,functions:notifyFamilyChatMessage
   ```

2. アップロード済みの最大versionCodeより大きいビルド番号で署名済みAABを生成し、Google Playのクローズドテストを更新する。
3. 通知用端末識別子の追加をプライバシーポリシー・データセーフティ申告へ反映する。

## 実機確認

家族2アカウント、Android端末2台で以下を確認する。FCMの実配信はエミュレータ上の単体テストでは確認できない。

- 初回ログイン時に通知を許可し、相手から送信する。前面の別画面・バックグラウンド・端末ロック時の音、振動、通知欄を確認。
- バックグラウンドと終了状態の両方で通知をタップしてチャットが開き、メッセージが既読になることを確認。
- チャット閲覧中、自分の送信、既読済み、子どもの利用停止中は通知されないことを確認。
- チャットを開いたままアプリをバックグラウンドにし、新着が既読にならず通知されることを確認。
- 通知許可拒否後もチャットが使えること、設定から再許可すると登録が再試行されることを確認。
- 同じ端末で別アカウントへ切り替え、以前のアカウントの通知が届かないことを確認。
- Androidの強制停止後は一度手動で起動するまでFCM通知が届かない。
