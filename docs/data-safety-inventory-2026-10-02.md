# 収集データ・SDK・データセーフティ照合表

2026-10-14追記：Androidの新着通知にFirebase Cloud Messagingを追加。
端末トークン・ユーザーID・登録更新日時を`chatPushDevices`に保存し、通知配送時に送信者の表示名と本文の一部をFCMで処理する。
Play Consoleの「デバイスまたはその他のID」および通知に関する収集目的の回答は、現在の申告を取得して照合する必要がある。Consoleの変更はまだ行っていない。

2026-10-02。対象は家族チャット、安全案内、成人確認、保護者の利用許可・停止を含む今回の公開予定版。投稿規約への同意と通報は `cd1eaa7` に保存したが本番反映は保留。これらの通報データを今回の公開版の収集項目には含めない。

**ユーザー提供のPlay Consoleプレビューを照合し、「データ収集なし」は実装と不一致と確認した。Consoleの変更・再提出は行っていない。** 個別設問の全回答、プレビューが提出済みか編集中の下書きかは直接取得していない。

## ユーザー提供のConsoleプレビューとの照合

2026-10-02受領。申告一覧ではデータセーフティ最終更新日は2026-09-14。

| 表示された申告 | 判定と対応 |
|---|---|
| データ収集は申告されていません | 不一致。Authにメール・認証情報・UID、Firestoreに表示名・本文・既読等を送るため「収集する」に修正し、下表の種類と用途を入力する。家族限定でも端末外への送信はなくならない |
| 第三者と共有されるデータはありません | 条件付き。委託先処理や本人が意図する家族への送信が共有例外に該当する範囲では維持可能。「Firebase利用＝必ず第三者共有あり」ではない。用途・契約を確認する |
| アプリ アカウントの削除：ルートURL | 受付経路は一致。メールによる申請窓口が存在する。エミュレーター検証は実運用の本人確認・削除完了を保証しない |
| アカウント全体を削除せず特定データを削除できる：ルートURL | 現在の公開用ページ・手順で裏付けなし。案内は家族全体／特定メンバーのアカウントと関連データの削除。アカウントを残す部分削除の受付・対象・処理を用意していない限り、この設問を「いいえ」に修正する |
| Playファミリーポリシーの遵守に努めています | 自己申告であり審査合格の証拠ではない。この表示だけで適合は判定しない |
| プライバシーポリシー：/privacy-policy | URLは一致・HTTP 200確認済み。安全確認等を追記した改訂文面は未公開 |

優先修正は「収集なし」の撤回と、未対応なら「アカウントを残す部分削除」の撤回。収集・共有・暗号化・削除の各設問は独立して回答する。画面の一般的な例示にある画像・動画・取引履歴を、本アプリが収集していると読み替えない。

ポリシーの直接URL `https://gyutto-cb454.web.app/privacy-policy` はHTTP 200を確認した。公開中のページには今回追記した成人確認等の説明がまだない。改訂文面はローカルソースのみで、Hosting公開は未実施。

## データ台帳

| 取得・保存するデータ | 保存先・根拠 | 目的／閲覧範囲 | 削除対象 |
|---|---|---|---|
| メール、パスワード、UID、認証状態 | Firebase Auth / auth_repository.dart | 認証・アカウント管理。子どもは匿名認証UID。パスワードはAuthで処理しFirestoreに保存しない | Authユーザー・トークン |
| 表示名、家族名、所属、役割、状態 | users、families、members | 家族管理・表示・権限制御。プロフィール内roleは権限の根拠にしない | 本人プロフィール・所属、他文書内の本人参照 |
| 本文、送信者UID・表示名、日時 | messages | 家族のチャット配信 | 本人投稿 |
| 既読者UID・表示名・時刻 | messages.readBy | 家族内の既読表示 | 本人の既読エントリだけ除去 |
| 招待ハッシュ、期限、利用者・作成者、参加申請・承認者 | invites、parentInviteCodes、childInviteTokens、joinRequests | 招待・参加の制御 | 関連招待と索引、本人申請、他者申請の本人参照 |
| 安全案内版・確認日時、成人自己申告版・確認方法・再認証時刻 | chatAccess | 安全確認とアクセス制御。生年月日・身分証・再認証パスワードは保存しない | 本人のchatAccess |
| 利用許可・停止状態、版、変更者・日時・履歴 | chatAccess、chatSafetyEvents | 保護者による管理 | 本人履歴、他者の記録内の本人参照 |
| 再設定申請と承認者等 | passwordResetRequests（既存スキーマ） | アカウント復旧。今回のクライアント直接書込は拒否 | 本人申請、他者申請内の本人参照 |
| IP、SDK・OS等の技術情報、インストール識別子・トークン、関数名 | Firebase SDK・クラウドサービス | 認証、通信、不正利用防止、サービス維持 | サービス側の保持手順。アプリDB削除と別 |
| 問い合わせ・削除申請メール、本人確認情報 | 運営Gmail | 問い合わせ・本人確認・削除 | 完了後30日以内に受付メールボックスから削除する運用 |
| 削除対象UIDと処理日時 | accountDeletions（今回追加、未デプロイ） | 古いトークンのアクセス阻止 | Auth削除後2時間以上待ち、残存データを確認後に削除 |

ユーザーが自由文に書いた情報は本文として保存される。任意の本文を解析して位置・健康などの別用途で利用する機能はない。自由文の入力可能性と、別目的での抽出・利用を混同しない。

## データセーフティ入力案

| 設問・データ分類 | 今回の回答案 | 根拠・確定条件 |
|---|---|---|
| データを収集するか | はい | 認証情報・UID・チャット等が端末外へ送信される |
| 氏名 | 収集あり／アプリ機能・アカウント管理 | 表示名は仮名でも本人アカウントに関連付く。登録に必要 |
| メールアドレス | 収集あり／アカウント管理 | 親・管理者の登録に必要、子どもには不要。任意／必須は子ども経路を含むConsoleの設問定義に照合 |
| ユーザーID | 収集あり／アプリ機能・アカウント管理・不正利用防止 | 全アカウントのUID。必須 |
| その他のアプリ内メッセージ | 収集あり／アプリ機能 | 本文・送信者・日時・既読。送信は任意。サーバーに保持するため一時処理ではない |
| その他のユーザー生成コンテンツ | 収集あり／アプリ機能 | 家族名など。利用経路ごとの入力要否を確認 |
| アプリの操作 | 収集あり／アプリ機能・不正利用防止 | 参加承認、安全案内確認、成人確認、利用許可変更・既読等。Analytics SDKの有無とは別 |
| その他の個人情報 | 収集あり／アプリ機能・アカウント管理 | 家族内の役割、所属、成人自己申告等 |
| デバイスまたはその他のID | 収集あり／アプリ機能・不正利用防止 | FID、IID/FCM系トークン、認証サービスの識別情報を考慮 |
| 診断・その他のパフォーマンスデータ | 要確定 | SDKの技術情報・サービスログの用途を、実機通信とConsole設定に照合。Crashlyticsなしを理由に全技術情報を否定しない |
| おおよその位置情報 | IPから位置を推定・利用している場合は収集あり | アプリの位置取得・推定処理はない。IPの取得と位置推定は別。サービス側利用を確認して確定 |
| 第三者との共有 | 下記の例外に該当する範囲は「共有」に数えない案 | Firebaseへの委託処理、利用者が意図する家族への送信。契約・実際の用途・設問の例外に該当するか確認して確定 |
| 通信の暗号化 | はい（FirebaseのHTTPS/TLS） | E2EEではない。外部サービスへの遷移も確認対象 |
| 削除をリクエストできるか | はい | 設定→削除申請ページ→メール。自動削除とは申告しない |
| アカウント作成方法 | ユーザー名とパスワード（メール＋パスワード）と子どもの匿名アカウント経路を説明 | OAuth・電話番号認証は使わない。実際のConsole選択肢に合わせる |
| セキュリティ独立審査 | 受けていなければ「いいえ」 | 今回のテストを第三者認証とは扱わない |

共有の例外が使えてもポリシーには実際の提供先・家族への共有を記載する。多くの情報はアカウントに紐づき長期保存されるため、全体を「一時的な処理」と申告しない。メール申請はアプリ内でメール本文を取得する機能ではないが、運営による取り扱いとしてポリシーに記載する。
